# Security

DotGame.Imaging decodes images that may come from anywhere, so a file that makes it crash, hang, read or
write outside its buffers, or use far more memory than its size suggests is a security problem.

Please report one privately, not in a public issue: use GitHub's private vulnerability reporting for this
repository (the Security tab, "Report a vulnerability"). Include the file that causes it, if you can.

Fixes go into the latest version only.
